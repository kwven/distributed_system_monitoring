=== AGENT DE SURVEILLANCE ===

1. INSTALLATION DE JAVA (si non installé):
   - Exécutez install-java.bat
   - Ou installez Java 17 manuellement

2. DÉMARRAGE:
   - Double-cliquez sur start-agent.bat
   - Entrez l'adresse IP du serveur
   - L'agent démarre automatiquement

3. CONFIGURATION RÉSEAU:
   - Serveur: Adresse IP de la machine avec le serveur
   - Ports: 9999 (UDP) et 9998 (TCP) doivent être ouverts

4. ARRÊT:
   - Appuyez sur Ctrl+C dans la fenêtre
   - Ou fermez la fenêtre
